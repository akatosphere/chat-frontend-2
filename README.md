# Документация

## Соглашения

### Работа с типами

- **Расположение:** Стараемся соблюдать хранение типов в папке соответствующей сущности
- **Dto и типы для ui:** Типы, использующиеся для работы
  с **сервером** обозначаются "Dto" в конце названия. Типы для работы внутри приложения (camelCase) без "Dto"
- **Без дублирования:** Все специфичные типы расширяют базовый через пересечение типов (`&`).
- **Запрет на `interface`:** Используются только `type`.

### Типы

**Сущность: Пользователь**

- `Превью` UserPreview — Облегченная структура для отображения авторов сообщений и кратких упоминаний.
- `Участник чата` ChatMember — Расширенная структура участника чата. Содержит статус `is_online`, дату последнего входа и флаги отношений (блокировка, контакты).
- `Профиль` User — Максимально полная структура профиля. Включает персональные данные (email, телефон, пол) и системные флаги (`is_filled`, `is_doctor`).

**Сущность: Контакт**

- `Системный профиль контакта` ContactSystemContactDto — Вложенный в контакт объект системного пользователя (аватар, статус сети, время последнего входа).
- `Сырые данные контакта` ContactDto — Объект записи из телефонной книги пользователя, содержащий локально заданные имена и вложенный системный профиль.
- `Сырой ответ списка контактов` ContactListResponseDto — Пагинированная структура ответа от сервера, содержащая массив объектов ContactDto и метаданные страниц.
- `Контакт` Contact — Основная UI-модель, объединяющая превью пользователя (UserPreview) с локальными именами, номером телефона и статусом присутствия.
- `Обработанный список контактов` ContactListResponse — Маппированная структура для TanStack Query и Zustand стора, содержащая плоский список моделей Contact.
- `Данные для добавления` AddByPhonePayload — Структура тела запроса для добавления нового контакта в систему по номеру телефона.

**Shared / API (Базовые типы бэкенда)**

- Общий результат операции. `Result` — обертка для успешных или ошибочных ответов.
- Ошибки валидации полей. `ValidationError` — словарь, где ключ — имя поля, значение — массив ошибок.
- Общая текстовая ошибка. `MessageError` — структура для вывода простых сообщений об ошибках с бэкенда.
- Сырой объект файла. `ApiFile` — описание вложения, хранящегося на сервере.
- Сырой объект сообщения. `ApiMessage` — полная структура сообщения со всеми связями в формате бэкенда.

**Entities / Chat (Бизнес-сущность Чата)**

- Категория чата. `ChatType` — перечисление: личный чат, группа или канал.
- Краткая информация о последнем сообщении. `LastMessage` — облегченная версия сообщения для превью в списке чатов.
- Технические данные чата. `ChatObject` — детальная информация о чате для административных функций.
- Элемент списка чатов. `ChatItemData` — агрегированный объект для рендеринга карточки в боковой панели.
- Ответ списка чатов. `ChatListResponse` — структура пагинированного списка чатов.
- Состояние доставки (базовое). `MessageStatus` — статус сообщения для логики сущности.
- Сводка вложений. `FilesSummary` — краткий счетчик типов и количества файлов в сообщении.
- Иконка предпросмотра файла. `PreviewIconType` — визуальный тип вложения (фото, видео или файл).
- Превью последнего сообщения. `LastMessagePreview` — текстовая и иконочная сборка для списка чатов.

**Shared / WebSocket (Транспортный уровень)**

- Ответ сервера на экшен. `WSStatusResponse` — статус выполнения запроса по сокету (OK или ERROR).
- Состояние соединения. `WSStatus` — жизненный цикл сокета (подключение, онлайн, реконнект).
- Базовый пакет данных. `WSBaseResponse` — универсальный формат любого входящего сообщения по сокету.
- Функция-обработчик. `WSHandler` — описание коллбэка для обработки входящих событий.
- Запрос в очереди. `QueuedRequest` — структура для хранения сообщений, ожидающих отправки при обрыве связи.

**Features / Chat & List (UI-логика)**

- Состояние списка чатов. `ChatListState` — данные для Zustand-стора списка чатов.
- Маппинг вложения. `FileAttachment` — упрощенная структура файла для отображения в пузыре сообщения.
- Маппинг сообщения для UI. `Message` — основная единица данных сообщения, готовая для рендеринга.
- Группировка сообщений. `MessageGroupType` — структура для отображения сообщений, разделенных по датам.

**Shared / UI (Компоненты)**

- Элемент меню. `MenuItem` — описание кнопки в выпадающих списках или навигации.
- Карта иконок. `MenuIcon` — словарь React-компонентов иконок.
- Доступные действия. `MenuAction` — список системных команд, вызываемых через меню.

**Прочие (Feature/Widget специфичные)**

- Данные формы создания. `CreateGroupFormValues` — тип, выведенный из Zod-схемы создания группы.
- Статус активности. `UserStatus` — расширенный статус пользователя (включая "печатает").
- Результат верификации кода. `VerificationResult` — состояние процесса входа после ввода OTP.
