# Документация модуля списка чатов (Chat List Feature)

Данный модуль реализует функционал списка чатов приложения. Он обеспечивает отображение, поиск, фильтрацию и бесконечную прокрутку (infinite scroll) чатов. Архитектура построена на связке **React**, **Zustand** (для локального стейт-менеджмента) и **TanStack Query** (для работы с сервером).

## 📂 Обзор архитектуры

Модуль следует методологии, близкой к Feature-Sliced Design (FSD):

- **`features/`**: Основная логика фичи (контейнеры, связывание стора и UI).
- **`entities/`**: Бизнес-сущности (типы чата, мапперы, базовые UI-компоненты).
- **`shared/`**: Общие переиспользуемые компоненты (UI-кит, утилиты).

## 🧩 Ключевые компоненты

### 1. `ChatsListPanel` (Точка входа)

Главный компонент-обертка для боковой панели чатов.

- **Путь**: `features/chat-list/ui/chatsListPanel.tsx`
- **Функциональность**:
  - Содержит локальный стейт строки поиска (`search`).
  - Рендерит шапку с компонентом `Searchbar` и кнопкой создания чата `CreateChatBtn`.
  - Оборачивает основной список `ChatListContainer` в контейнер с прокруткой.

### 2. `ChatListContainer` (Smart Component)

Контейнер логики, отвечающий за загрузку и подготовку данных.

- **Путь**: `features/chat-list/ui/chatListContainer.tsx`
- **Логика**:
  - **Загрузка данных**: Использует хук `useChatsInfinite` для пагинации.
  - **Связь со стором**: Получает данные из Zustand-стора `useChatListStore`. Использует селектор `useShallow` для оптимизации ререндеров. Данные хранятся в нормализованном виде (`chatsByKey`), но для рендера преобразуются в массив на основе массива `order`.
  - **Фильтрация**: Применяет клиентскую фильтрацию через `filterChats` на основе поискового запроса.
  - **Бесконечная прокрутка**: Реализует `IntersectionObserver` через `loadMoreRef`. Когда пользователь доскролливает до невидимого элемента внизу, вызывается `fetchNextPage`.
  - **Состояния**: Обрабатывает индикаторы загрузки (`isLoading`) и ошибки (`isError`).

### 3. `ChatList` (Dumb Component)

Презентационный компонент для отображения списка.

- **Путь**: `features/chat-list/ui/chatList.tsx`
- **Функциональность**:
  - Принимает массив чатов и флаг поиска.
  - Если список пуст, отображает соответствующие заглушки (`InfoMessage`):
    - "У вас пока нет чатов" (если это не поиск).
    - "Поиск не дал результатов" (если чаты не найдены по запросу).
  - Рендерит список через `ChatListItemComponent`, передавая каждому чату набор действий (`actions`).

### 4. `ChatListItemComponent` (Элемент списка)

Компонент отдельной строки чата.

- **Путь**: `features/chat-list/ui/chatListItem.tsx`
- **Особенности**:
  - **Контекстное меню**: Подключает хук `useChatListItemContextMenu` для обработки правого клика (закрепить, удалить, отключить уведомления).
  - **Роутинг**: Является ссылкой (`Link`) на страницу чата. Формирует URL в зависимости от типа чата (группа/канал или личка).
  - **Визуал**: Отображает аватар, статус "онлайн", имя, превью последнего сообщения и счетчик непрочитанных.
  - **Стилизация**: Подсвечивает активный чат (`isActive`), фавориты и состояние открытого контекстного меню.

## 📦 Управление состоянием (State Management)

В модуле используется гибридный подход: **Server State** (TanStack Query) + **Client State** (Zustand).

### Zustand Store (`useChatListStore`)

Служит единым источником правды для списка чатов на клиенте. Это позволяет легко обновлять список из разных мест (например, при приходе WebSocket события).

**Структура стора**:

```typescript
{
  chatsByKey: Record<string, ChatListItem>; // Нормализованное хранилище (О(1) доступ)
  order: string[]; // Массив ключей для сохранения порядка сортировки
  count: number; // Общее количество чатов
}
```

**Основные действия**:

- `mergeChats`: Сливает новые страницы данных (с сервера) с текущим состоянием.
- `upsertChat`: Обновляет существующий чат или добавляет новый (Upsert). Пересчитывает порядок сортировки (`applyChatOrder`).
- `patchChat`: Точечное обновление полей чата (например, статуса "печатает" или счетчика).
- `removeChat`: Удаление чата из локального стейта (оптимистичный UI).

### TanStack Query (`useChatsInfinite`)

Отвечает за получение данных с API и управление кэшированием запросов.

- **Синхронизация**: Использует `useEffect` для перекладывания полученных данных (`lastPage.results`) в Zustand-стор через `mergeChats`.
- **Query Key**: `["chats"]`.

## 🌐 Взаимодействие с API

### 1. Получение списка (`getChatList`)

- **Метод**: `GET /api/v1/chat/list/`
- **Параметры**:
  - `page_size`: 12 (размер страницы).
  - `ordering`: `-is_favorite,-last_activity_at` (сначала избранные, потом по времени активности).
- **Маппинг**: Ответ сервера проходит через `mapChatList` перед попаданием в стор.

### 2. Удаление чата (`clearChat`)

- **Метод**: `DELETE /api/v1/chat/list/{index}/`
- **Типы**: Возвращает `Result<ClearChatSuccess>`.

## 🛠 Хуки и Вспомогательные функции

- **`useChatListActions`**: Фасад для действий над чатом. Позволяет компонентам вызывать бизнес-логику (toggleFavorite, clearChat) без знания деталей реализации API.
- **`filterChats`**: Утилита для фильтрации списка на клиенте (по названию).
- **`applyChatOrder`**: Утилита для сортировки ключей чатов (обеспечивает правильный порядок при добавлении новых сообщений).

## 🎨 UI и Стилизация

Используется **Tailwind CSS** с утилитой `cn` (clsx + tailwind-merge) для условного применения классов.

- **Скроллбар**: Кастомный класс `.list-scrollbar`.
- **Адаптивность**: Использование модификаторов `desktop:` для специфичных стилей десктопа.
- **Иконки**: SVG-компоненты (импортируются как React-компоненты, например `@icons/chat/pin.svg`).

## 📝 Пример использования

Компонент `ChatsListPanel` полностью самодостаточен и может быть встроен в любой лэйаут:

```tsx

const Sidebar = () => {
  return (
    <aside className="h-screen w-[320px] border-r bg-white">
      <ChatsListPanel />
    </aside>
  );

```
