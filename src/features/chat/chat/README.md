## Компоненты

| Файл                       | Описание                                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `chat.tsx`                 | Главный компонент чата. Инициализирует данные, устанавливает WebSocket-соединение, рендерит список сообщений и футер      |
| `messageList.tsx`          | Список сообщений с группировкой по датам. Управляет прокруткой, авто-прочтением, показывает кнопку прокрутки вниз         |
| `messageGroup.tsx`         | Группа сообщений за одну дату. Содержит бейдж с датой и массив сообщений, вычисляет отступы между сообщениями             |
| `messageBubble.tsx`        | Обёртка сообщения. Определяет позиционирование (слева/справа), обрабатывает двойной клик для ответа, управляет подсветкой |
| `messageLayout.tsx`        | Макет пузыря сообщения. Задаёт цвет, форму, максимальную ширину, рендерит блоки содержимого                               |
| `messageText.tsx`          | Текст сообщения с временем и иконкой статуса доставки. Поддерживает эмодзи и корректный перенос текста                    |
| `messageReply.tsx`         | Превью сообщения, на которое отвечаем. Клик переходит к оригинальному сообщению                                           |
| `messageForwarded.tsx`     | Информация о пересланном сообщении: аватар и имя отправителя                                                              |
| `messageBlockRenderer.tsx` | Диспетчер типов блоков. Делегирует рендеринг соответствующему компоненту (text/reply/forwarded/file)                      |
| `dateBadge.tsx`            | Бейдж с датой между группами сообщений                                                                                    |
| `scrollDownBtn.tsx`        | Кнопка прокрутки вниз. Появляется, когда пользователь прокрутил список вверх                                              |
| `replyBox.tsx`             | Индикатор режима ответа. Отображается над полем ввода, показывает превью сообщения для ответа                             |

## Состояние (stores)

| Файл                        | Описание                                                                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `useChatStore.ts`           | Хранилище чата: список сообщений, ID текущего пользователя, ключ чата, цель для ответа, методы добавления/обновления сообщений |
| `useChatNavigationStore.ts` | Навигация по сообщениям: целевое сообщение для перехода, подсветка, счётчик запросов                                           |
