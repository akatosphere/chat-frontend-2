### 1. Entities (Сущности)

Лежат в основе бизнес-логики.

- **`entities/contact`**:
  - `api/`: Запросы к эндпоинтам `/messenger-list/`, `/messenger-add-by-phone/`, `/messenger-delete-contact/`. Разделены на клиентские и серверные (`getContactsServer`) для поддержки SSR.
  - `model/store.ts`: Zustand-стор для хранения списка контактов (`contacts`), их общего количества и состояния инициализации.
  - `model/mappers.ts`: Чистые функции для преобразования DTO от бэкенда в интерфейс `Contact`. Важно: обрабатывают различия в структурах системного пользователя и записи в книге контактов.
  - `lib/useContactsSync.ts`: Хук-связка. Подтягивает данные через TanStack Query и синхронизирует их с Zustand-стором.
  - `ui/contactCard.tsx`: Базовый компонент карточки (Avatar + Name + Online Status).

### 2. Features (Фичи)

Пользовательские действия, несущие бизнес-ценность.

- **`features/contacts/model/SelectContactsStore.ts`**: Общий Zustand-стор для управления режимом выбора (Selection Mode). Хранит массив `selected` и флаг `isSelecting`. Используется **и на странице контактов (для удаления), и в создании чата**.
- **`features/contacts/deleteContacts`**: Логика массового удаления.
  - `useDeleteSelectedContacts.ts`: Mutation, которая параллельно удаляет выбранные контакты и обновляет кэш.
- **`features/contacts/addToContacts`**: Позволяет добавить пользователя из глобального поиска в свой список контактов.
- **`features/createChat`**:
  - `ui/submitCreateChatBtn.tsx`: Кнопка финализации создания чата. Собирает данные из `useCreateChatStore` и UID выбранных контактов из `useSelectContactsStore`.

### 3. Widgets (Виджеты)

Самостоятельные блоки страницы, собирающие фичи и сущности.

- **`widgets/contactsList`**:
  - `ui/contactsPage.tsx`: Основной составной виджет страницы контактов.
  - `lib/useGlobalContactsSearch.ts`: Реализует логику **Debounce-поиска** (500мс) по глобальной базе пользователей.
  - `lib/useContactsLogic.ts`: "Мозг" виджета. Фильтрует локальные контакты, исключает дубли из глобального поиска и управляет флагами отображения (`showLoader`, `showNoResults`).
- **`widgets/createChat`**:
  - `ui/step2.tsx`: Виджет выбора участников. Переиспользует логику синхронизации контактов, но принудительно включает режим выбора через `useStep2Logic`.

## 🚀 Основные механизмы

### Поиск (Локальный + Глобальный)

Поиск работает по комбинированному принципу:

1.  **Локально**: Фильтрация уже загруженных контактов в Zustand-сторе (по имени, телефону, никнейму).
2.  **Глобально**: Если введен поисковый запрос, через 500мс отправляется запрос к API пользователей.
3.  **Мерж**: Глобальные результаты фильтруются так, чтобы в списке "Пользователи А-чата" не отображались те, кто уже есть в ваших контактах.

### Пагинация и Infinite Scroll

Используется `useInfiniteQuery` из TanStack Query.

- Точкой входа является `useContactsSync`.
- Для отслеживания прокрутки используется кастомный хук `useInfiniteScroll` (Intersection Observer), который вешается на `ref` в конце списка.

### Режим выбора (Multi-selection)

Реализован через `SelectContactsStore`. Это позволяет:

- На странице контактов: Нажать на "Корзину" -> Выбрать несколько -> Удалить.
- В создании чата: Выбрать участников -> Нажать "Создать".
  Компонент `ContactCardFeature` автоматически меняет свое поведение (переход в чат vs Checkbox) в зависимости от состояния `isSelecting`.
